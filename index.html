      How NEWNAME decides

      Cards & Luhn

      13–19 digit candidates are checked with the Luhn checksum algorithm (mod 10). Valid cards (Visa, Mastercard, Amex, RuPay) are redacted; order numbers that fail Luhn are set aside.

      Aadhaar & Verhoeff

      Aadhaar numbers must have 12 digits, start with 2–9, and pass the dihedral Verhoeff checksum table. Numbers with failing checksums or starting with 0/1 are excluded.

      PAN Holder Validation

      5 letters + 4 digits + 1 letter. The 4th character must be a registered Indian taxpayer type (P, C, H, F, A, T, B, L, J, G). Non-matching patterns are marked as decoys.

      Disguised Data

      De-obfuscates disguised emails (e.g. name [at] domain [dot] com), spaced mobile numbers, and Devanagari digits (०-९) to ensure no leaked entity escapes.

      Names via Gemini Nano

      Extracts complex Indian names and physical addresses using local on-device Chrome Prompt API. Anti-hallucination verification filters out any entity not literally present in the raw text.

      Your Text Stays Here

      Zero telemetry, zero analytics, zero external network requests. AES-256-GCM encryption with PBKDF2 ensures only authorized holders can reverse pseudonymisation.
